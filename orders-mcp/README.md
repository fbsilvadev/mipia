# orders-mcp

A small, read-only [Model Context Protocol](https://modelcontextprotocol.io) server that lets an AI assistant (Claude Desktop, Claude Code, Cursor) answer questions about a SQLite orders database.

It is a working example of what I deliver for clients: **an MCP server for your API or database, tested and documented, in 5 days.**

## What it does

| Tool | Purpose |
|---|---|
| `search_orders` | Filter by customer, status and date range (max 100 rows) |
| `get_order` | One order with its line items |
| `sales_summary` | Revenue and order count by month or status |

Design choices that matter in production:

- **Read-only connection.** The database is opened with `mode=ro`, so the assistant cannot change data even if a prompt asks it to.
- **Parameterized SQL only.** No string-built queries from user input.
- **Input validation.** Malformed dates and unknown ids return clear tool errors.
- **Bounded results.** Every list is capped so one question cannot flood the model's context.

## Run it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python seed.py          # creates orders.db with 120 fictional orders
python test_server.py   # end-to-end test through a real MCP client
python server.py        # starts the server over stdio
```

## Connect it to Claude Desktop

Add this to `claude_desktop_config.json`, using absolute paths:

```json
{
  "mcpServers": {
    "orders": {
      "command": "/absolute/path/to/.venv/bin/python",
      "args": ["/absolute/path/to/server.py"]
    }
  }
}
```

Then ask: "Which customer had the most shipped orders in June?" or "Show revenue by month."
